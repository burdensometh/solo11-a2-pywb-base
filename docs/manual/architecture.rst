Architecture
============

The pywb system consists of 2 distinct components: Warcserver and Rewriter, which can be run and scaled separately.
The default pywb wayback application uses Warcserver and Rewriter.

Additionally, the indexing system is used through all components, and a few command line tools encompass the pywb toolkit.
